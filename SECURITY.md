# Security reporting

SECTOR is pre-release and has no supported production versions. Do not use it for real-world ATC or assume live-network approval.

Use GitHub private vulnerability reporting when available under the affected repository Security tab. Otherwise contact the maintainer privately through https://github.com/Tfc538 to arrange a secure channel. Do not put vulnerabilities, tokens, personal information, or private network captures in public issues. No response-time commitment is established yet.
