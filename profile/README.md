# SECTOR

**A new perspective on control.**

Building a cross-platform virtual air traffic control workstation with Rust, TypeScript, React, WebGPU, and a planned tablet companion.

Early development: the current code is a starter scaffold, not an operational controller client. Network and voice integration remain subject to applicable approvals.

Start with the [main repository](https://github.com/sector-atc/sector), [roadmap and issues](https://github.com/sector-atc/sector/issues), and [discussions](https://github.com/sector-atc/sector/discussions).

SECTOR is independent and is not affiliated with, endorsed by, or officially approved by VATSIM. It is not for real-world air traffic control.
